# מחשבון

מחשבון פשוט בדפדפן: קובץ HTML אחד, בלי תלויות ובלי שלב build.

## מה יש בו

- ארבע פעולות החשבון, עם סדר פעולות נכון (כפל וחילוק לפני חיבור וחיסור)
- אחוזים, החלפת סימן ומחיקת ספרה
- היסטוריית חישובים שנשמרת בדפדפן (localStorage); לחיצה על תוצאה מחזירה אותה למחשבון
- תמיכה במקלדת: ספרות, `+ - * /`, `Enter`, `Backspace`, `Esc`, `%`
- מצב כהה ובהיר לפי הגדרות המערכת
- מותאם למובייל

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן.

### סביבת הפיתוח ב־Base44

```sh
docker compose -f docker-compose.base44.yml up -d
```

התצוגה המקדימה זמינה בפורט `3000`. קובץ המקור מחובר ישירות לקונטיינר לקריאה בלבד, ו־`live-server` מרענן את הדפדפן בעת שינוי `index.html` — אין שלב build. כלי הפיתוח מותקן בגרסה קבועה בעת הפעלת הקונטיינר ונשמר ב־Docker volume נפרד; ההפעלה הראשונה דורשת גישה ל־npm. בדיקת התקינות ב־Compose מוודאת שדף המחשבון מוגש.

אין צורך במפתחות API, במסד נתונים או בהגדרות סודיות. היסטוריית החישובים נשמרת רק בדפדפן. טעינת הגופן מ־Google Fonts היא אופציונלית, עם גופני מערכת כחלופה. ההגדרות הן לשרת הפיתוח בלבד; אין שינוי בהתנהגות האפליקציה ואין צורך ב־`BASE44_PREVIEW_MODE`.

לעצירה: `docker compose -f docker-compose.base44.yml down`.

## פרסום ב־GitHub Pages

1. לדחוף את הריפו ל־GitHub
2. ב־**Settings → Pages** לבחור **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`
3. אחרי דקה בערך האתר יהיה זמין בכתובת `https://<user>.github.io/<repo>/`
